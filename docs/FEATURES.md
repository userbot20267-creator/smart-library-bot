## 🧠 البحث الدلالي (Semantic Search)

### الوصف

### المثال
- **استعلام:** "كتب عن التطور البشري"
- **النتائج:** قد تعرض كتباً تتحدث عن "النشوء والارتقاء" أو "تاريخ الإنسان"
- **السبب:** المتجهات الدلالية لهذه المصطلحات متقاربة

```python
# في bot/services/search/semantic_search.py
query_embedding = await ai_service.generate_embedding_text(query)

similarity = cosine_similarity(query_vector, book_vector)
```

## 📦 نظام الباقات (Packs System)

### الوصف
يجمع الكتب في مسارات منظمة للقراءة، مثل:
- 🎯 تعلم البرمجة من الصفر
- 🧠 تطوير الذات والقيادة
- 📚 الأدب العربي الكلاسيكي

### البنية
```python
class Pack:
    name: str           # اسم المسار
    description: str    # الوصف
    items: List[PackItem]  # الكتب بالترتيب

class PackItem:
    book: Book          # الكتاب
    order: int          # الترتيب
    notes: str          # ملاحظات
```

```python
# تفعيل/تعطيل
```

## 💬 نظام التعليقات

### الميزات
- ➕ إضافة تعليق
- ❤️ إعجاب بالتعليق
- 📊 عدد الإعجابات
- 👤 اسم المستخدم

## 🤖 أدوات الذكاء الاصطناعي للمالك

### 1. توليد وصف تلقائي
أثناء إضافة كتاب، يولد AI وصفاً جذاباً.

### 2. اقتراح قسم تلقائي
يحلل عنوان الكتاب والمؤلف ويقترح القسم الأنسب.

### 3. إعادة تصنيف ذكية
```
/ai_recategorize
```
يحلل جميع الكتب في "غير مصنف" ويوزعها تلقائياً.

### 4. تحليل شامل للمكتبة
```
/ai_insights
```
يعطي تقريراً ذكياً يشمل:
- نقاط القوة والضعف
- اقتراحات كتب جديدة
- توصيات للتحسين

### 5. البحث الذكي والإضافة التلقائية
```
/ai_search رواية الخيميائي --قسم روايات
```
يبحث في المصادر الخارجية ويضيف الكتاب تلقائياً.

## 📦 الرفع الدفعي (Batch Upload)

### الوصف
